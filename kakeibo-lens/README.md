# 家計簿レンズ

マネーフォワード ME の「入出金」CSVを読み込んで、MFの画面では見づらい分析をまとめて出すダッシュボードです。
ビルド不要の HTML 1枚で、外部ライブラリは使っていません（グラフも自前のSVGで描いています）。

## 使い方

### A. マネーフォワードから直接取り込む（おすすめ）

1. ダッシュボードの「⇩ MFから取り込む」ボタンをブラウザのブックマークバーへドラッグ（初回だけ）。ドラッグできない環境では「コードをコピー」で新しいブックマークのURL欄に貼り付け
2. マネーフォワード ME にログインした画面で、そのブックマークをクリック
3. 取得する月数（3〜36か月）を選んで「取得する」→「コピー」
4. ダッシュボードに戻って貼り付け（Ctrl+V / ⌘V）。「ファイルで保存」した JSON を読み込んでも同じです

ブックマークは、ログイン中のブラウザから MF の「ダウンロード」ボタンと同じURL（`/cf/csv?from=…&month=…&year=…`）を月ごとに0.5秒間隔で読むだけで、パスワードはどこにも渡しません。
※ 開発環境から moneyforward.com に接続できないため、実際のMFでの動作確認はまだです。

### B. CSVを手で読み込む

1. マネーフォワード ME（PCブラウザ）で「家計簿」→「入出金」を開く
2. 月を切り替えながら「ダウンロード」→「CSVファイル」で各月を保存（プレミアム会員の機能）
3. ダッシュボードの「CSVを読み込む」で選ぶか、画面にドラッグする（複数ファイルを一度に読み込めます）

同じ月を読み込み直すと、その月の明細は最新の内容に置き換わります（`ID` 列で重複を除き、ファイル名の期間内で消えた明細は削除）。

## 見られるもの

| タブ | 内容 |
|---|---|
| 概要 | 今月の支出、前月比・過去6か月平均比、収入・貯蓄率・固定費・変動費・特別な支出、月初からの累計ペース（前月・平均と重ねる）、気になる動き（平均から外れた中項目、新しく出てきた支出、大きな買い物、回数の多いお店、予算超過）、大項目別の内訳（タップで中項目、直近12か月のミニグラフ付き） |
| 推移 | 大項目／中項目／固定・変動の積み上げ棒グラフと3か月移動平均、月×項目の表（色で「金額の大きさ」か「平均との差」を表示、数字をタップで明細へ） |
| 比較 | 前月・前年同月・直近3か月・直近6か月の比較で、中項目ごとに増えたもの・減ったものを並べる |
| 明細 | お店・サービス別ランキング、定期的な支払い（サブスク）の自動検出と値上がり検知、日ごとのカレンダー、曜日別の1日平均、検索できる明細一覧 |
| 設定 | 月の開始日（給料日始まりに対応）、中項目ごとの「固定／変動／除外」、大項目ごとの月予算、読み込み済みの月の管理、JSONバックアップ |

## 集計ルール

- `計算対象=0` と `振替=1` の明細は集計しません（カード引き落としや、Amazon明細とカード明細の二重計上はMF側の振替設定がそのまま効きます）
- 大項目「収入」と、未分類のプラス金額は収入として扱います
- それ以外のプラス金額（返金）は、同じ項目の支出から差し引きます
- 「その他 › 会社経費」「その他 › 立替金」は最初から集計の対象外です（設定で変更できます）
- 固定費の初期設定は 住宅・水道光熱費・通信費・保険・税社会保障。中項目ごとに変更できます

## データの保存先

- **claude.ai の Artifact として開いた場合**: Artifact のデータベースに保存されます。アクセスルールでオーナー本人だけが読み書きできるようにしてあり、PC とスマホ（Claude アプリ）で同じデータが見られます
- **`index.html` を直接開いた場合**: ブラウザの localStorage に保存されます（外部には送信しません）

## ファイル構成

- `src/dashboard.html` … 本体（claude.ai Artifact として公開する形式）
- `index.html` … `src/dashboard.html` を単体のHTMLとして包んだもの。`python3 scripts/build.py` で作り直します
- `scripts/build.py` … 上記の生成スクリプト

## 独立したリポジトリに移すとき

このフォルダの中身をそのまま新しいリポジトリにコピーすれば動きます。GitHub Pages で公開する場合は `index.html` をルートに置いてください（データはコードに含まれないので、公開リポジトリでも家計の数字は外に出ません）。
