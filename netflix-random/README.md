# Netflix ランダム再生（Chrome 拡張機能）

気分やジャンル、再生時間、種別から Netflix の作品をランダムにピックし、そのまま再生できる Chrome 拡張機能です。

## インストール

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」でこの `netflix-random` フォルダを選ぶ
4. ツールバーの 🎲 アイコンを押すと、ピック画面が新しいタブで開く

## 使い方

| 項目 | 内容 |
| --- | --- |
| 選び方 | 「気分で」（😂 笑いたい、😭 泣きたい など12種）か「ジャンルで」（25ジャンル）を選ぶ |
| 再生時間 | 複数選べる。映画は本編の長さ、シリーズは1話の長さで判定する |
| 種別 | 指定なし / 映画 / シリーズ |
| 件数 | 5・10・20・30件 |
| ピック | 条件に合う作品をランダムに選ぶ。見つかった順にカードが出る |
| ♡ | カード右上でお気に入りに追加。「お気に入り」ボタンで一覧を表示する |
| この中からおまかせ再生 | 表示中のカードから1本を選んで、再生画面を開く |

「視聴する」を押すと `netflix.com/watch/<ID>` が開きます。再生には Netflix へのログインが必要です。
右上には、かかった時間（一覧取得・詳細取得・fetch の平均×回数・キャッシュ利用数）が出ます。

## しくみ

- 作品の一覧は Netflix の公開ジャンルページ（`netflix.com/jp/browse/genre/<ID>`）、あらすじや再生時間は公開作品ページ（`netflix.com/jp/title/<ID>`）から読みます。
- ログイン中の会員画面は中身が変わるため、Cookie を送らずに取得しています。アカウントの情報は読みません。
- 一覧は12時間、作品の詳細は7日間 `chrome.storage.local` にキャッシュします。フッターの「キャッシュを削除」で消せます。
- 直近に出した作品は後回しにして、同じ作品が続けて出にくくしています。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `manifest.json` | 拡張機能の設定（Manifest V3） |
| `background.js` | アイコンを押したらピック画面を開く |
| `app.html` / `app.css` / `app.js` | ピック画面 |
| `catalog.js` | Netflix の公開ページの取得・解析とピック処理 |
| `genres.js` | ジャンルID、気分とジャンルの対応、再生時間の区切り |
| `store.js` | `chrome.storage.local` のラッパー |

気分とジャンルの対応は `genres.js` の `MOODS` を書き換えれば変えられます。

## 注意

- Netflix の公開ページの作りが変わると、一覧やあらすじが読めなくなることがあります。そのときは `catalog.js` の `parseGenrePage` / `parseTitlePage` のセレクタを直してください。
- 対象は日本の公開カタログです。お住まいの地域や契約で見られない作品が混ざることがあります。
